# Work a straightforward SFI action query

This is a linear task. Each top-level heading below is one step. Work them in order, from opening the case to closing it.

## Step 1 — Open and assign the case

- From the SITI Agri Main menu, select **Case Management**.
- Under **Category**, find the **SFI action query** case and select the folder icon to open it.
- Check the seven-digit Application/Case ID matches the contract you have been asked to work.
- Assign the case to yourself using the person icon in the **Owner** field.

Before you take ownership, check with the current owner (if one is shown) that they are not already working the case.

## Step 2 — Read the case notes

Note down the following from the case notes:

- the parcel ID
- the action (option code)
- the scheme year

If any of these are missing, refer the case to your Team Leader before continuing.

## Step 3 — Check the action against the agreement

Open the agreement in SITI Farmer and compare the recorded action against the case.

Does the action on the agreement match the action in the case notes?

- **Yes** — continue to Step 4.
- **No** — record the discrepancy in your notes. You will still complete the checks, but flag it at Step 5.

## Step 4 — Confirm the parcel is eligible

Navigate to the **Land** tab and locate the parcel.

Check that the parcel:

- is still linked to the SBI
- has an eligible land cover for the action
- has no open mapping cases

If all three are true, the query can be resolved. If any is not, follow the **Operations Resolution** route and place the case on hold.

## Step 5 — Record your decision

Add a case note using the standard template:

> SFI action query — parcel `<parcel ID>`, action `<option code>`.
> Checks completed: agreement match, eligibility, mapping.
> Decision: `<resolve / hold / refer>`.
> `<name and date>`

## Step 6 — Close the case

- Confirm every line under **Status** shows a green icon.
- Select the tick icon to close the case.
- Check the status changes to **CLOSED**.

Once the case shows as closed, return to the case list and pick up the next query.
