# SFI hold codes and escalation routes

This is a reference guide. Officers do not read it end to end — they look up the hold code or route they need. Use the contents list to jump to a section.

## About hold codes

A **hold code** records why a case cannot progress and what it is waiting on. Applying the right code keeps the case out of the active work queue and tells the next person what happened.

Always add a case note when you apply a hold, explaining what you are waiting for and who you have referred it to.

## Hold code reference

| Code | Name | When to use | Owner |
| --- | --- | --- | --- |
| HOLD901 | Awaiting customer response | You have written to the agreement holder and are waiting for a reply | Processor |
| HOLD972 | Referred to Operations Resolution Team | The case has been escalated and is awaiting a decision | Team Leader |
| HOLD980 | Awaiting mapping change | A mapping request has been raised and the case cannot progress until it completes | GI Operations |
| HOLD990 | Awaiting policy decision | The case raises a question policy has not yet answered | Policy |

Only one hold code should be active on a case at a time. If a case is waiting on more than one thing, hold on the code that blocks progress first.

## Escalation routes

### Operations Resolution route

Use this when you cannot resolve a case on the desk and need a decision.

1. Refer to your Team Leader in the first instance.
2. If the Team Leader cannot resolve it, they escalate to the Operations Resolution Team.
3. The Team Leader applies **HOLD972** and adds a case note.
4. When a response is received, remove the hold and continue as directed.

### GI Operations referral

Use this when a parcel has been delinked or mapped in error and needs correcting.

1. Confirm the error through the mapping and tenure checks.
2. Raise a referral to GI Operations describing the parcel and the correction needed.
3. Apply **HOLD980** while the mapping change is worked.

### Policy referral

Use this only when guidance does not cover the situation.

1. Write up the question and the case facts.
2. Send it to the Policy inbox through your Team Leader.
3. Apply **HOLD990** until an answer is received.

## Reverting a case from hold

To return an on-hold case to active work:

- Open the case in SITI Agri.
- Set the status back to **In Progress**, following the SFI SITI Agri Basic Navigation guide, section "Revert an on-hold case to in progress".
- Remove the hold code and add a case note recording the response you received.
